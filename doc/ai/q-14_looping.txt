❯ Explain how the R1 and R2 file will be paired for the same sample

● The glob only matches R1 files, and the R2 path is built from each R1 path by
  string substitution, so the two files always share the same sample ID.

  1. ../garrigos/fastq/S6*_R1.fastq.gz expands to the R1 files of the samples
     whose ID starts with S6. Examples are ../garrigos/fastq/S63_R1.fastq.gz and
     the others like it. The loop variable R1 holds one of these paths per
     iteration.
  2. ${R1/_R1.fastq.gz/_R2.fastq.gz} is bash pattern substitution. It takes the
     value of R1 and replaces the first _R1.fastq.gz with _R2.fastq.gz. For
     example, ../garrigos/fastq/S63_R1.fastq.gz becomes
     ../garrigos/fastq/S63_R2.fastq.gz.
  3. Only the suffix changes. The directory and sample ID (S63) stay the same,
     so R1 and R2 come from the same sample.

  Both paths are then passed to trimgalore.sh as $1 and $2, which runs
  trim_galore --paired on that pair.

  The pairing relies on the naming convention <sample>_R1.fastq.gz and
  <sample>_R2.fastq.gz, which matches the files in ../garrigos/fastq. If an R2
  file were missing, the script's existence check would stop with an error.
